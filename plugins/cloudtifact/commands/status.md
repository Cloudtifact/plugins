---
description: Show what's published on Cloudtifact, unpublished changes and open comments
---

Following the cloudtifact skill:

- In a repo with a `.cloudtifact.json`, run `cloudtifact status --toon` and `cloudtifact comments --toon`, and summarise unpublished changes and open threads.
- Otherwise run `cloudtifact artifacts` and list what the user has published, with links.
